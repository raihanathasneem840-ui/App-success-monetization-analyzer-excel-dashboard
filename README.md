# Google Play Store Data Analysis Dashboard

## 📊 Project Overview

This project presents an **Excel-based analysis of Google Play Store applications**, focusing on app categories, ratings, reviews, installation levels, pricing, content ratings, and overall app distribution.

The workbook combines **data cleaning, pivot-table analysis, KPI reporting, and an interactive-style dashboard** to turn a large app dataset into clear business insights.

The goal of the project is to demonstrate how Excel can be used to explore large datasets, identify patterns, and communicate findings through concise visual reporting.

---

## 🎯 Objectives

- Analyse the distribution of applications across different categories.
- Compare **free and paid applications**.
- Examine average app ratings by category.
- Understand the distribution of apps by content rating.
- Analyse installation trends across app categories.
- Create summary KPIs for quick business-level interpretation.
- Present the findings through an Excel dashboard.

---

## 🗂️ Dataset

The project uses a Google Play Store applications dataset containing approximately **10,800 app records**.

Key fields include:

- **App** – Application name
- **Category** – Google Play Store category
- **Rating** – User rating
- **Reviews** – Number of reviews
- **Size** – Application size
- **Installs** – Installation range
- **Type** – Free or Paid
- **Price** – Application price
- **Content Rating** – Target audience classification
- **Genres** – Application genre
- **Last Updated** – Last update date
- **Current Ver** – Current application version
- **Android Ver** – Required Android version

Additional cleaned fields were created for analysis, including numeric installation and price values.

---

## 🧹 Data Preparation

The workbook includes a dedicated **DATA** sheet where the dataset was prepared for analysis.

Key preparation steps included:

- Cleaning installation values and converting them into usable numeric values.
- Cleaning price values for analysis.
- Structuring the dataset for pivot-table analysis.
- Preparing the data for category-level and KPI-based reporting.

---

## 📈 Analysis Performed

The workbook contains five major pivot-table analyses:

1. **Apps by Category**  
   Measures the number of applications available in each Play Store category.

2. **Free vs Paid Apps**  
   Compares the distribution of free and paid applications.

3. **Average Rating by Category**  
   Compares average user ratings across app categories.

4. **Apps by Content Rating**  
   Examines how applications are distributed across audience/content-rating groups.

5. **Applications by Category and Install Data**  
   Summarises application distribution using cleaned installation values.

## 💡 Key Takeaways

- The dataset is heavily dominated by **free applications**, with 10,039 free apps in the workbook's KPI summary.
- The overall average rating is approximately **4.19**, indicating generally strong user ratings across the dataset.
- The dataset contains billions of recorded reviews, providing a useful basis for understanding user engagement at scale.
- Category-level analysis makes it possible to compare app availability and rating performance across different market segments.
